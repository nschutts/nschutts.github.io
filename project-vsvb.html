Vehicle System Validation Board (VSVB)

IN PROGRESS

A PCB testing board purpose-built for FSAE electrical validation.

This season I am working on the Vehicle System Validation Board, a PCB validation unit used for system level benchtop testing of the wiring harness. The board will interface directly with the Haltech Nexus S2 ECU, PDM, and dashboard to simulate analog, digital, and reluctor sensor inputs, with the goal of facilitating testing for drive-by-wire implementation.
For this project, I will be developing firmware using C++ wrapped around CMSIS_V2 FreeRTOS to manage real-time task scheduling and signal simulation, as well as writing test cases to implement the testing suite after development.
